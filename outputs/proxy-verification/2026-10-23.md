# Hỗ trợ HTTP proxy và mặc định HTTP — 23/10/2026

## Thay đổi

- Form cấu hình có lựa chọn HTTP, HTTPS, SOCKS5 và SOCKS5H; mặc định là HTTP.
- Địa chỉ và dòng import không ghi giao thức mặc định dùng HTTP.
- Dòng import có tiền tố giao thức được giữ đúng loại, ví dụ `socks5://host:port:user:pass`.
- Android VPN chuyển kết nối HTTP/HTTPS proxy qua HTTP CONNECT; cùng đường kết nối phục vụ GeckoView, tra IP và tra múi giờ.
- Cầu nối chỉ lắng nghe trên loopback và yêu cầu thông tin xác thực ngẫu nhiên riêng. Đổi/dừng cấu hình đóng các socket cũ.
- HTTPS proxy xác minh chứng chỉ TLS. HTTP CONNECT hỗ trợ Basic authentication và TCP; không chuyển tiếp UDP.

## Kiểm tra đã qua

- 12 kiểm thử Flutter cho mặc định HTTP, đổi giao thức, nhập cấu hình, tra múi giờ bằng mock và khôi phục proxy gốc.
- 3 kiểm thử parser import cho địa chỉ, thông tin đăng nhập và dữ liệu không hợp lệ.
- 5 kiểm thử native Java bằng socket loopback và thông tin giả: CONNECT có xác thực, truyền hai chiều/half-close, giữ dữ liệu gửi ngay sau header, xử lý HTTP 407, xác thực cục bộ, từ chối UDP, đóng kết nối và từ chối hạ cấp khi TLS lỗi.
- Phân tích 9 file Dart liên quan: không có vấn đề.
- Build release ARM64 thành công: `build/app/outputs/flutter-apk/app-release.apk`, khoảng 217,6 MB.

Khi chạy rộng hơn, các kiểm thử widget trong `proxy_import_test.dart` cũ có lỗi dữ liệu Data Mail/giả định User-Agent không còn phù hợp. Đã chạy riêng ca `import persists proxy and account together after review` trên bản sao mã HEAD trước thay đổi HTTP: ca đó cũng thất bại tại kiểm tra danh sách cấu hình đã lưu. Không coi bộ kiểm thử import cũ là đã qua toàn bộ.
